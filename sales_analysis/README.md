# Business Sales Performance Analytics

This folder contains a complete, easy-to-submit solution for the Future Interns Data Science & Analytics Task 1 (2026).

## Files
- sales_data.csv: synthetic sales dataset with order, product, region, revenue, cost, and profit columns
- sales_summary.txt: executive summary with key metrics and recommendations
- sales_dashboard.html: client-ready dashboard in HTML format
- analyze_sales.py: Python script that generates the dataset and report

## How to run
From this folder, run:

```bash
python analyze_sales.py
```

## What this solution includes
- Clean, structured sales data
- Revenue and profit analysis
- Monthly trend insights
- Top product, category, and region analysis
- Business recommendations for growth

## Suggested submission note
This project uses a simple, realistic sales dataset to demonstrate business analytics thinking and can be presented as a client-ready analysis report.
